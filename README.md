# Ιστοσελίδα Μαρίας Κατσαρά

Επαγγελματική ιστοσελίδα για τη Μαρία Κατσαρά, ψυχολόγο και παιδοψυχολόγο στη Ρόδο. Παρουσιάζει την προσέγγισή της, τις υπηρεσίες για παιδιά και γονείς και τα στοιχεία επικοινωνίας του γραφείου.

Η ιστοσελίδα είναι φτιαγμένη με HTML, CSS και JavaScript. Η διάταξη προσαρμόζεται σε κινητό και υπολογιστή και οι κινήσεις σέβονται τη ρύθμιση μειωμένης κίνησης.

## Τοπική προβολή

Άνοιξε το [index.html](index.html) στον browser. Η σελίδα δεν χρειάζεται εγκατάσταση ή build.
